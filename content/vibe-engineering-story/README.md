# Vibe Engineering storytelling workspace

This folder contains the article, diagrams, capture plans and production assets for explaining
Astragentic through the shift from Vibe Coding to Vibe Engineering.

## Core message

> Vibe Coding optimizes the moment code is created. Vibe Engineering optimizes the system
> that moves a change from intent to production in a repeatable, observable and verifiable way.

## Intended reader

- Founders and technical owners already using AI coding agents.
- Tech leads beginning to coordinate several agents or several tickets at once.
- Developers who have experienced agent collisions, lost context or unbounded review loops.

## Story rule

Astragentic enters the story only after the reader has felt the operational problem. Features
are explained through a real project lifecycle and backed by visible evidence, not a catalogue
of product claims.

## Files

| Path | Purpose |
|---|---|
| `01-outline.md` | Current article structure and narrative beats |
| `02-media-plan.md` | Visual grammar, diagram list and capture sequence |
| `drafts/01-first-draft.md` | First complete article draft for collaborative editing |
| `assets/images/` | Approved diagrams, illustrations and screenshots |
| `assets/clips/` | Approved source captures and edited clips |

## Production order

1. Approve the outline and the project-management act.
2. Choose one real feature to carry through the whole story.
3. Turn each visual placeholder into a shot or diagram brief.
4. Capture the real workflow before generating decorative imagery.
5. Write the first draft around the approved evidence.
6. Edit clips and create final publishing assets.
