# Align with evidence

Read the effort, current PRD, relevant code and boundary decisions. Capture the owner's
brain dump before narrowing. Maintain a frontier with question, type (fact/decision),
answer, source and open/resolved status. Sources are concrete file/line, ADR, measured
run, research or dated owner statement. A plausible answer without a source stays open.

Investigate facts yourself. Ask decisions in small coherent rounds through Thomas for
a dispatched Shaper; never let a peer's inference stand in for owner choice. Check
contradictions against current code and preserve a Source conflict note rather than
silently rewriting history. Update authorized documents as answers settle and retain
links to evidence. Avoid copying whole logs into context.

Conclude with confirmed seams, constraints, open frontier and sources. Only proceed
to spec when the owner has confirmed the decisions needed for that scope. A blocked
question can be handed back with the exact missing evidence; do not shrink the effort
without agreement. Save this frontier before waiting or compaction.
