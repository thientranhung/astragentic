# Linear adapter

Read project tracker settings for workspace/team/project, ticket prefix and state
mapping. Discover available Linear connector tools and inspect their schema; tool
names or fields from another environment are not authority. Resolve current IDs before
mutating. Pagination and account write limits matter; an incomplete list is not an
empty frontier and a quota failure is not successful ticket publication.

Use native workflow states, parent relations and blocked-by edges. Preserve existing
labels/relations when editing arrays. Read back changed issue state and edge direction.
Blocking is not necessarily inherited from a parent; inspect parent readiness too.
External prerequisites need a tracked dependency or an explicit unresolved gate.

An assignee is a workspace member, not a unique Builder. Keep worker identity in the
Codex dispatch record and arbitrate exclusive work through claim/worktree ownership.
Never release an uncertain claim simply because the same account name appears.

Materialize readiness in the configured ready state after all actual prerequisites
are satisfied. Do not assign during shaping. Close only on verified disposition with
authorization; preserve IDs during revisions. Reconcile an uncertain create by its
source/dispatch identity before repeating. Report partial publication and limits.
